普通和破损分别计数；同一皮肤的格式或来源副本不重复计数。旧收藏中无法确认皮肤编号的记录保留 `archive`。游戏各区服、联动和下架装扮没有可供逐条核验的官方完整目录。上述统计只描述已核对的公开来源。另用 GFL Archive 的人形索引按角色代号、皮肤编号和普通／战损形态交叉核对，394 个不同组合均在目录中。[对照索引](https://github.com/steve1316/gfl-archive/blob/6c4c26a8157b1e000ea2160ab0549ec17b85340e/src/data/live2d-index.json)

对四份下载来源逐一检查后，457 个首选模型清单引用的文件均存在。在全部 1,317 个不同来源清单中，有 32 个备用入口引用了缺失文件（Eikanya 31 个、dump 1 个），另有 99 条 Eikanya 来源记录只有模型二进制。目录保留这些记录供溯源，默认选择可加载的入口。

当模型带游戏对话配置时，播放器按命中部位、普通或破损形态、动作名和 ID 匹配台词与日语录音，保留游戏配置的播放延迟。复核 dump 中的 2,840 份动作文件，2,839 份的曲线计数与导出内容不符。加载器按实际曲线重算新版动作的段数和控制点数，修正部分导出文件会被 Cubism 拒绝播放的问题；原始下载文件按固定提交保存。带游戏事件配置的点击动作播放一遍，待机动画继续循环。模型台词会持续到动作与声音都结束，再保留 1.2 秒淡出。有模型台词或匹配的翻译时优先显示；点击动作或语音缺少台词时，新旧播放器均从 `waifu-tips.json` 的 `click` 中选取适用于 `#live2d` 的预设提示，保持到本次互动结束。仅点击画布而未触发动作时短暂显示预设。预设文字不会触发额外录音。少女前线入口默认显示简体中文，语音保持日语。字幕按角色代号和语音编号复用，原始模型仍保留上游台词。1,340 个中文字幕键覆盖当前对话数据中全部有英文原文的条目，其中 11 条为项目翻译。缺少文字的语气声保留原录音。中文角色名、装扮名和绝大多数字幕取自[固定版本的国服数据表](https://github.com/gf-data-tools/gf-data-ch/tree/c6c763ca71e6f8450232fbd30e26900c51d2c09b)。

目录和顺序切换共用同一份排序。妖精在最前，按一阶到三阶排列。同一人形的编号装扮按国服装扮表的实装批次顺序排列，同批次按数字编号，普通排在对应战损前面。原版先于装扮，可核实的心智升级按国服开放时间插入，缺少批次的造型置于已知批次之后。[国服装扮表](https://github.com/gf-data-tools/gf-data-ch/blob/c6c763ca71e6f8450232fbd30e26900c51d2c09b/stc/skin.json)

少女前线人物在载入时按可见轮廓决定展示区的宽高比，站姿留足高度，横向小队可以用满可用宽度。网页角落默认最多占 480 × 410 CSS 像素，并随窗口缩小。图鉴以预览区为上限。竖向全身轮廓目标占画布高度的 93%，脚底下方约留 3%。横向展开的造型会按宽度等比缩小。水平中心优先参考模型标记的头部和躯干，缺少标记时按照可见像素分布居中。动作期间镜头固定。切换时保留上个角色的一帧，直到新角色完成取景并画好才替换。背景沿用原构图。

## 重建目录和图鉴

用 `node scripts/model-library.mts <Eikanya checkout> <jacksen168 checkout>` 重建固定来源，再执行 `node scripts/localize-library.mts <本地完整素材目录>` 合并中英文名称、字幕和旧档映射。英文名称与旧语音键使用[固定美服数据](https://github.com/gf-data-tools/gf-data-us/tree/5be9af6692083246bd288b9326d0e576dbecb4f0)，新版模型英文台词取自对应动作的原始对话记录。对于仅有内嵌原句的旧版索米模型，项目提供逐句英文翻译。

运行 `node scripts/catalog-portraits.mts <本地完整素材目录>` 为新增造型生成缩略图。历史分类由 `scripts/girls-frontline-catalog.mts` 生成。内置素材按角色家族分为七个固定 GitHub 快照，每包预算 38 MB。模型素材更新使用 `node scripts/cdn-snapshot.mts <提交> --publish`。
